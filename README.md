# TechUtsav India Hero

Build a premium responsive TechUtsav India landing page. Focus only on header + hero. Desktop: logo left, nav Home, Events, Community, Opportunities, Resources, About, Join Community button right. Hero is a two-column editorial composition: left has eyebrow "IDEAS • PEOPLE • OPPORTUNITIES", concise headline "India Builds Together", one short supporting line about an India-wide technology community, and "Join Our WhatsApp Community" CTA. Right has a rich Indian heritage arch/street illustration with monument silhouette, plants/flowers and an auto-rickshaw, inspired by a premium Indian festival/editorial aesthetic. Keep the existing TECHUTSAV INDIA logo unchanged if an asset is available; otherwise create a clear placeholder for the logo asset rather than redesigning it. Cream/off-white background, deep forest green, terracotta/orange, mustard/gold and subtle teal. Use elegant display serif typography like Cormorant Garamond or Bodoni Moda, restrained script accent, and Manrope/DM Sans for UI. Do not over-decorate. Mobile must be a deliberate vertical redesign with hamburger menu, not a shrunken desktop. Support 320, 375, 768, 1024 and 1440 widths. Use responsive clamp typography, semantic accessible HTML, optimized assets, clean React/Tailwind components and subtle GSAP entrance animations. Do not create extra sections yet. Make it production-quality and visually close to the reference direction I described in chat.
